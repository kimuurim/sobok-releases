# Sobok

화면에 사계절이 내리는 작은 앱이에요. 겨울엔 창 윗변과 독(작업 표시줄) 위에 눈이 **소복이** 쌓여요.

| | 받기 | 지원 |
|---|---|---|
| 🍎 맥 | **[Sobok-mac.zip](https://github.com/kimuurim/sobok-releases/releases/latest/download/Sobok-mac.zip)** | macOS 13 이상 · Apple 실리콘·인텔 |
| 🪟 윈도우 | **[Sobok-windows.zip](https://github.com/kimuurim/sobok-releases/releases/latest/download/Sobok-windows.zip)** | Windows 10 · 11 (64비트) · 설치 프로그램 없음 |

무료예요. 아래는 맥 기준 설명이고, 윈도우는 [윈도우에서 쓰기](#윈도우에서-쓰기) 를 보세요.

---

## 1. 설치

1. 위 링크로 `Sobok-mac.zip` 을 받아 더블클릭해서 풀어요.
2. 나온 **Sobok** 앱을 Finder 의 **응용 프로그램** 폴더로 끌어다 놓아요.
3. Sobok 을 더블클릭해서 열어요.

### "확인되지 않은 개발자" 경고가 뜨면 (처음 한 번만)

앱스토어 앱이 아니라서 처음 열 때 macOS 가 막아요. 한 번만 허용하면 다음부터는 바로 열려요.

1. 경고 창에서 **완료**(또는 취소)를 눌러 닫아요.
2. **시스템 설정 › 개인정보 보호 및 보안** 으로 가서 맨 아래로 내려요.
3. "Sobok 이(가) 차단되었습니다" 옆의 **그래도 열기** 를 누르고, 암호를 넣어요.

> 터미널을 쓸 줄 알면 이 한 줄로도 돼요: `xattr -dr com.apple.quarantine /Applications/Sobok.app`

### 독 위에도 눈이 쌓이게 하려면 (선택)

창 위에는 권한 없이 쌓여요. **독** 위치를 읽으려면 손쉬운 사용 권한이 필요해요.

- 처음 실행할 때 뜨는 창에서 **시스템 설정 열기** › 손쉬운 사용 목록에서 **Sobok** 을 켜요.
- 나중에 하려면: Sobok 설정 › **쌓임** › **권한 설정 열기**.

## 2. 사용 방법

Sobok 은 독에 아이콘이 없어요. 화면 오른쪽 위 **메뉴막대의 말랑한 캐릭터 아이콘** 을 눌러서 써요.

| 메뉴 | 하는 일 |
|---|---|
| 눈 멈추기 / 눈 내리기 | 잠깐 끄고 켜기 (끄면 아이콘이 흐려져요) |
| 설정… | 설정 창 열기 |
| 지금 눈 채우기 | 창·독 위를 처음 두께만큼 바로 채우기 (겨울) |
| 쌓인 눈 치우기 | 쌓인 눈 전부 치우기 |
| 종료 | 끄기 |

### 계절

설정 › **계절** 에서 고르고 **저장** 을 눌러요. "달에 따라 자동으로 바꾸기" 를 켜 두면 알아서 바뀌어요 (3~5월 봄 · 6~8월 여름 · 9~11월 가을 · 12~2월 겨울).

| 계절 | 화면 | 독 위 |
|---|---|---|
| ⛄️ 겨울 | 눈이 내려 창·독 위에 쌓여요 | 눈사람 · 꼬마전구 · 🎄 |
| 🌸 봄 | 벚꽃이 팔랑이며 내려와 잠깐 앉았다 사라져요 | 🌷 · 🦋 |
| 🏖️ 여름 | 🫧 거품이 아래에서 떠올라요 | 파도 · 🦀 🐚 · 비치볼(클릭하면 통!) |
| 🍁 가을 | 단풍·낙엽·은행잎이 뒤집히며 떨어져요 | 🎃 🍄 🌰 · 🐿️ |

### 겨울 놀이

| 하고 싶은 것 | 이렇게 |
|---|---|
| 눈덩이 만들기 | 두껍게 쌓인 눈을 클릭 |
| 굴려서 키우기 | 독이나 창 위 눈덩이를 옆으로 끌기 (지나간 자리 눈이 파여요) |
| 던지기 | 눈덩이를 더블클릭 |
| 눈사람 만들기 | 눈덩이를 들어 올려 다른 눈덩이 위에 놓기 (큰 쪽이 몸) · 독·창 위 어디서나 |
| 눈사람 부수기 | 눈사람을 10번 클릭 → 그 자리에 눈으로 다시 쌓여요 |
| 눈사람 옮기기 | 눈사람을 끌기 |

창을 끌면 쌓인 눈·눈덩이·눈사람이 같이 따라오고, 세게 흔들거나 창을 내리면 우수수 떨어져요.

마우스를 휙 움직이면 그쪽으로 바람이 불어 눈·꽃잎·낙엽이 날려요 (설정 › 내리는 것 에서 끌 수 있어요).

### 설정 창

| 탭 | 내용 |
|---|---|
| 계절 | 계절 고르기 · 자동 |
| 내리는 것 | 양 · 떨어지는 속도 · 크기 · 바람 · 흔들림 · 마우스로 바람 일으키기 · 눈 모양 |
| 쌓임 | 처음 두께 · 쌓이는 속도 · 최대 두께 · 독 위에도 쌓기 |
| 꾸미기 | 계절마다 독 위 꾸미기 켜고 끄기 · 꾸미기 크기(작게·보통·크게) · 12월에만 꾸미기 |
| 일반 | 내릴 모니터(듀얼 모니터) · 로그인할 때 자동 실행 · 업데이트 확인 · 기본값 |

바꾼 내용은 **저장** 을 눌러야 화면에 반영돼요. **되돌리기** 를 누르면 저장된 값으로 돌아가요.

## 3. 업데이트

**설정 › 일반 › 지금 확인** 을 누르면 바로 확인해요. 켜 두면 하루 한 번 알아서도 확인하고, 새 버전이 있으면 메뉴 맨 위에 **✨ 새 버전 … 업데이트…** 가 떠요.

**1.6 부터 (버튼 한 번)**
1. 지금 확인 → 새 버전이 있으면 **지금 업데이트** 버튼이 나와요.
2. 누르면 받는 중(%) → 설치 중 → 잠깐 꺼졌다가 **새 버전으로 다시 켜져요**. 설정·권한은 그대로예요.

**1.5 를 쓰고 있다면 (이번 한 번만 직접)**
1.5 에는 자동 설치가 없어서 **받기** 를 누르면 이 페이지가 열려요. 위에서 새 zip 을 받아 풀고, 메뉴 › 종료 후 응용 프로그램 폴더의 Sobok 을 새 것으로 **바꾸기** 하고 다시 열어 주세요. 그다음부터는 버튼 한 번이면 돼요.

## 4. 자주 묻는 것

**독에는 안 쌓이고 창에만 쌓여요**
손쉬운 사용 권한이 꺼져 있어요. 설정 › 쌓임 에서 "허용됨" 이 보이는지 확인해 주세요. 업데이트한 뒤 꺼졌다면 목록에서 Sobok 을 껐다 켜 주세요.

**메뉴막대에 아이콘이 안 보여요**
메뉴막대 아이콘이 많으면 노치 뒤로 숨어요. 다른 아이콘을 ⌘ 누른 채 끌어서 빼 주세요.

**화면 아래 창을 클릭할 때 방해되지 않나요?**
눈·꽃잎은 클릭이 그대로 통과해요. 클릭을 받는 건 눈사람·눈덩이·비치볼과 두껍게 쌓인 눈 위뿐이에요.

**배터리·CPU 를 많이 쓰나요?**
설정 › 내리는 것 › **양** 을 줄이면 가벼워져요. 잠깐 끄려면 메뉴 › 눈 멈추기.

**지우고 싶어요**
메뉴 › 종료 후 응용 프로그램 폴더에서 Sobok 을 휴지통에 넣으면 끝이에요.

## 윈도우에서 쓰기

### 설치

1. 위 표에서 `Sobok-windows.zip` 을 받아 **마우스 오른쪽 → 압축 풀기** 해요.
2. 나온 **Sobok.exe** 를 원하는 폴더(예: 문서 › Sobok)에 두고 더블클릭해요. 설치 과정은 없어요.
3. **"Windows의 PC 보호"** 파란 창이 뜨면 (처음 한 번만): **추가 정보** → **실행**.
   스토어 앱이 아니라서 뜨는 안내예요.

권한 설정은 필요 없어요. 창과 작업 표시줄 위에 바로 쌓여요.

### 쓰는 법

화면 오른쪽 아래 **알림 영역**(시계 옆, 안 보이면 `^` 안)에 Sobok 아이콘이 생겨요. 아이콘은 지금 계절 그림(⛄🌸🏖️🍁)이에요.

- **왼쪽 클릭**: 설정 창
- **오른쪽 클릭**: 메뉴 (눈 멈추기 · 설정… · 지금 눈 채우기 · 쌓인 눈 치우기 · 종료)

계절, 겨울 놀이, 설정 창 내용은 맥과 같아요 (위 설명에서 "독" 을 "작업 표시줄" 로 읽으면 돼요). 설정 창에서 바꾼 것은 **저장**(또는 Ctrl+S)을 눌러야 반영돼요.

- 아이콘이 `^` 안에 숨어 있으면: 끌어서 작업 표시줄로 꺼내 두면 편해요.
- 컴퓨터 켤 때 자동으로: 설정 › 일반 › **로그인할 때 자동 실행**.
- 영상·게임을 전체 화면으로 보면 Sobok 은 그 화면에서 잠깐 숨어요.
- 작업 표시줄이 화면 아래에 있을 때만 그 위에 쌓여요.

### 업데이트 · 지우기

- 설정 › 일반 › **지금 확인** → **지금 업데이트** 를 누르면 받아서 바꾸고 다시 켜져요 (1.6 부터). 설정은 그대로예요.
- 1.5 를 쓰고 있다면 이번 한 번만: 새 zip 을 받아 메뉴 › 종료 후 Sobok.exe 를 새 것으로 바꿔 넣어 주세요.
- 지우기: 메뉴 › 종료 → Sobok.exe 삭제. 설정까지 지우려면 `%APPDATA%\Sobok` 폴더도 삭제. 자동 실행을 켰다면 먼저 설정에서 꺼 주세요.
