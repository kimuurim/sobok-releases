# Sobok 배포

화면에 사계절이 내리는 macOS 메뉴막대 앱 **Sobok** 의 설치 파일을 받는 곳이에요.

## 설치

1. [Releases](../../releases/latest) 에서 `Sobok-mac.zip` 을 받아 풀고, `Sobok.app` 을 "응용 프로그램" 폴더로 옮겨요.
2. 처음 열 때 "확인되지 않은 개발자" 경고가 뜨면: 시스템 설정 › 개인정보 보호 및 보안 › 아래쪽 **그래도 열기** (한 번만).
3. 메뉴막대 아이콘 › 설정… 에서 계절·양·꾸미기를 고르고 **저장**.
4. 독 위에도 눈이 쌓이게 하려면: 설정 › 쌓임 › **권한 설정 열기** › 손쉬운 사용에서 Sobok 켜기.

macOS 13 이상, Apple 실리콘·인텔 모두 돼요.

## 업데이트

앱이 하루 한 번 이 저장소의 최신 릴리스를 확인해요. 새 버전이 있으면 메뉴막대 메뉴 맨 위에 **✨ 새 버전 받기…** 가 떠요.
받은 zip 을 풀어 응용 프로그램 폴더의 Sobok 을 바꿔 주세요. 설정과 권한은 그대로 유지돼요.
