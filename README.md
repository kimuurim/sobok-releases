# Sobok

화면에 사계절이 내리는 macOS 메뉴막대 앱이에요. 겨울엔 창 윗변과 독 위에 눈이 **소복이** 쌓여요.

**👉 [최신 버전 받기 (Sobok-mac.zip)](https://github.com/kimuurim/sobok-releases/releases/latest/download/Sobok-mac.zip)**

macOS 13 이상 · Apple 실리콘·인텔 모두 · 무료

---

## 1. 설치

1. 위 링크로 `Sobok-mac.zip` 을 받아 더블클릭해서 풀어요.
2. 나온 **Sobok** 앱을 Finder 의 **응용 프로그램** 폴더로 끌어다 놓아요.
3. Sobok 을 더블클릭해서 열어요.

### "확인되지 않은 개발자" 경고가 뜨면 (처음 한 번만)

앱스토어 앱이 아니라서 처음 열 때 macOS 가 막아요. 한 번만 허용하면 다음부터는 바로 열려요.

1. 경고 창에서 **완료**(또는 취소)를 눌러 닫아요.
2. **시스템 설정 › 개인정보 보호 및 보안** 으로 가서 맨 아래로 내려요.
3. "Sobok 이(가) 차단되었습니다" 옆의 **그래도 열기** 를 누르고, 암호를 넣어요.

> 터미널을 쓸 줄 알면 이 한 줄로도 돼요: `xattr -dr com.apple.quarantine /Applications/Sobok.app`

### 독 위에도 눈이 쌓이게 하려면 (선택)

창 위에는 권한 없이 쌓여요. **독** 위치를 읽으려면 손쉬운 사용 권한이 필요해요.

- 처음 실행할 때 뜨는 창에서 **시스템 설정 열기** › 손쉬운 사용 목록에서 **Sobok** 을 켜요.
- 나중에 하려면: Sobok 설정 › **쌓임** › **권한 설정 열기**.

---

## 2. 사용 방법

Sobok 은 독에 아이콘이 없어요. 화면 오른쪽 위 **메뉴막대의 말랑한 캐릭터 아이콘** 을 눌러서 써요.

| 메뉴 | 하는 일 |
|---|---|
| 눈 멈추기 / 눈 내리기 | 잠깐 끄고 켜기 (끄면 아이콘이 흐려져요) |
| 설정… | 설정 창 열기 |
| 지금 눈 채우기 | 창·독 위를 처음 두께만큼 바로 채우기 (겨울) |
| 쌓인 눈 치우기 | 쌓인 눈 전부 치우기 |
| 종료 | 끄기 |

### 계절

설정 › **계절** 에서 고르고 **저장** 을 눌러요. "달에 따라 자동으로 바꾸기" 를 켜 두면 알아서 바뀌어요 (3~5월 봄 · 6~8월 여름 · 9~11월 가을 · 12~2월 겨울).

| 계절 | 화면 | 독 위 |
|---|---|---|
| ⛄️ 겨울 | 눈이 내려 창·독 위에 쌓여요 | 눈사람 · 꼬마전구 · 🎄 |
| 🌸 봄 | 벚꽃이 팔랑이며 내려와 잠깐 앉았다 사라져요 | 🌷 · 🦋 |
| 🏖️ 여름 | 🫧 거품이 아래에서 떠올라요 | 파도 · 🦀 🐚 · 비치볼(클릭하면 통!) |
| 🍁 가을 | 낙엽이 뒤집히며 떨어져요 | 🎃 🍄 🌰 · 🐿️ |

### 겨울 놀이

| 하고 싶은 것 | 이렇게 |
|---|---|
| 눈덩이 만들기 | 두껍게 쌓인 눈을 클릭 |
| 굴려서 키우기 | 독 위 눈덩이를 옆으로 끌기 |
| 던지기 | 눈덩이를 더블클릭 |
| 눈사람 만들기 | 눈덩이를 들어 올려 다른 눈덩이 위에 놓기 (큰 쪽이 몸) |
| 눈사람 부수기 | 눈사람을 10번 클릭 |
| 눈사람 옮기기 | 눈사람을 끌기 |

창을 끌면 쌓인 눈이 같이 따라오고, 세게 흔들거나 창을 내리면 우수수 떨어져요.

### 설정 창

| 탭 | 내용 |
|---|---|
| 계절 | 계절 고르기 · 자동 |
| 내리는 것 | 양 · 떨어지는 속도 · 크기 · 바람 · 흔들림 · 눈 모양 |
| 쌓임 | 처음 두께 · 쌓이는 속도 · 최대 두께 · 독 위에도 쌓기 |
| 꾸미기 | 계절마다 독 위 꾸미기 켜고 끄기 · 12월에만 꾸미기 |
| 일반 | 내릴 모니터(듀얼 모니터) · 로그인할 때 자동 실행 · 업데이트 확인 · 기본값 |

바꾼 내용은 **저장** 을 눌러야 화면에 반영돼요. **되돌리기** 를 누르면 저장된 값으로 돌아가요.

---

## 3. 업데이트

앱이 하루 한 번 이 페이지의 최신 버전을 확인해요. 새 버전이 있으면 메뉴 맨 위에 **✨ 새 버전 받기…** 가 떠요 (설정 › 일반 › **지금 확인** 으로 바로 확인할 수도 있어요).

1. ✨ 새 버전 받기… 를 눌러 `Sobok-mac.zip` 을 받아 풀어요.
2. 메뉴 › **종료** 로 Sobok 을 끄고, 새 Sobok 을 응용 프로그램 폴더에 넣어 **바꾸기** 해요.
3. 다시 열어요. 설정과 권한은 그대로예요.

---

## 4. 자주 묻는 것

**독에는 안 쌓이고 창에만 쌓여요**
손쉬운 사용 권한이 꺼져 있어요. 설정 › 쌓임 에서 "허용됨" 이 보이는지 확인해 주세요. 업데이트한 뒤 꺼졌다면 목록에서 Sobok 을 껐다 켜 주세요.

**메뉴막대에 아이콘이 안 보여요**
메뉴막대 아이콘이 많으면 노치 뒤로 숨어요. 다른 아이콘을 ⌘ 누른 채 끌어서 빼 주세요.

**화면 아래 창을 클릭할 때 방해되지 않나요?**
눈·꽃잎은 클릭이 그대로 통과해요. 클릭을 받는 건 눈사람·눈덩이·비치볼과 두껍게 쌓인 눈 위뿐이에요.

**배터리·CPU 를 많이 쓰나요?**
설정 › 내리는 것 › **양** 을 줄이면 가벼워져요. 잠깐 끄려면 메뉴 › 눈 멈추기.

**지우고 싶어요**
메뉴 › 종료 후 응용 프로그램 폴더에서 Sobok 을 휴지통에 넣으면 끝이에요.
